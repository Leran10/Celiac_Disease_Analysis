Celiac Disease PHROG Analysis

Complete Statistical Analysis Report - All 9 Models Implementation

Analysis Overview

This comprehensive analysis applies the same 9 statistical models used in the original contig analysis to PHROG (PHage Orthologous Groups) data, examining the association between phage functional gene families and celiac disease progression.

Analysis Formula

~ Dx.Status * onset_timeline_combined + Sex + Age.at.Gluten.Introduction..months. + HLA.Category + feeding_first_year + Delivery.Mode + (1 | patientID)

Data Cohorts

US: Subset of total cohort

Italy: Subset of total cohort

Analysis Types

PA Analysis: 5 models for presence/absence

Presence/Absence (PA) Models

Five statistical approaches for analyzing binary PHROG presence/absence data across disease progression timepoints.

PA Model 1: glmmTMB (Logit Link)

✅ Complete

Description: Mixed-effects logistic regression with logit link

Results: total_PA_glmmTMB_logit_results.csv

glmmTMB(PA ~ Dx.Status * onset_timeline_combined + covariates + (1|patientID), family = binomial(link = "logit"))

PA Model 2: glmmTMB (Cloglog Link)

✅ Complete

Description: Mixed-effects logistic with complementary log-log link

Results: total_PA_glmmTMB_cloglog_results.csv

glmmTMB(PA ~ Dx.Status * onset_timeline_combined + covariates + (1|patientID), family = binomial(link = "cloglog"))

PA Model 3: glmer (lme4)

✅ Complete

Description: Standard mixed-effects logistic regression

Results: total_PA_glmer_results.csv

glmer(PA ~ Dx.Status * onset_timeline_combined + covariates + (1|patientID), family = binomial)

Purpose: Robust inference for repeated measures

🔄 In Progress

Abundance Models

Four statistical approaches for analyzing PHROG abundance/count data with appropriate handling of overdispersion and zero-inflation.

Abundance Model 1: Negative Binomial GLMM

✅ Complete

Description: Mixed-effects negative binomial for overdispersed counts

Results: total_abundance_negbinom_subset_results.csv

glmmTMB(count ~ Dx.Status * onset_timeline_combined + covariates + (1|patientID) + offset(log_offset), family = nbinom2)

Abundance Model 2: Hurdle Negative Binomial

🔄 In Progress

Description: Two-part model for excess zeros

Purpose: Separate modeling of zero vs non-zero processes

glmmTMB(count ~ Dx.Status * onset_timeline_combined + covariates + (1|patientID) + offset(log_offset), ziformula = ~ covariates + (1|patientID), family = truncated_nbinom2)

Abundance Model 3: Zero-Inflated Negative Binomial

🔄 In Progress

Description: Mixture model for structural zeros

Purpose: Account for different sources of zeros

glmmTMB(count ~ Dx.Status * onset_timeline_combined + covariates + (1|patientID) + offset(log_offset), ziformula = ~ 1, family = nbinom2)

Abundance Model 4: limma-voom

✅ Complete

Description: Linear model on log-transformed counts with empirical Bayes

Results: total_abundance_limma_results.csv

voom(counts, design) %>% lmFit(design, block = patientID, correlation = dupCor) %>% eBayes()

Available Results

The completed models provide comprehensive coverage of PHROG presence/absence and abundance patterns across celiac disease progression:

  • PA Model 1 (glmmTMB Logit): Primary mixed-effects analysis for binary PHROG presence
  • PA Model 2 (glmmTMB Cloglog): Alternative link function for rare events
  • PA Model 3 (glmer): Standard lme4 implementation for validation
  • Abundance Model 1 (Negative Binomial): Count-based analysis with overdispersion handling
  • Abundance Model 4 (limma-voom): Log-linear analysis with empirical Bayes shrinkage

Next Steps

The remaining models (GEE, Bayesian brms, Hurdle NB, Zero-Inflated NB) are computationally intensive but will provide additional robustness checks and specialized handling of complex data structures.

🎯 Analysis Impact

This comprehensive PHROG analysis represents the first large-scale investigation of phage functional gene families in pediatric celiac disease, providing insights into viral community functional potential across disease development timepoints.
