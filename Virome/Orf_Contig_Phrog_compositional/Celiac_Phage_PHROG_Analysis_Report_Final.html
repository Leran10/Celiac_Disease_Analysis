📋 Executive Summary

This report presents a comprehensive analysis of PHROG (PHage Orthologous Groups) presence/absence (PA) and abundance patterns in celiac disease patients compared to controls across multiple timepoints, providing functional insights into phage community changes.

🎯 Key Findings - PHROG-BASED FUNCTIONAL ANALYSIS

  • Functional Coverage: Successfully analyzed 1,111 PHROG families representing diverse phage functions
  • Statistical Models: Applied 5 PA models and 4 abundance models with robust mixed-effects framework
  • Biomarker Discovery: Identified 372 total PHROG biomarkers (125 PA + 247 abundance)
  • Sample Coverage: Total cohort: 308 samples across longitudinal design
  • Effect Magnitudes: Large effect sizes (log odds ratios -6.5 to +3.0) indicating strong biological signals
  • Temporal Detection: Changes detectable >42 months before clinical diagnosis

🧬 PHROG Functional Framework

PHage Orthologous Groups (PHROGs):

  • Functional Annotation: Groups of homologous phage genes with similar functions
  • Cross-Viral Comparison: Enables comparison across different phage types and families
  • Biological Context: Provides mechanistic insights into phage-host interactions
  • Standardized Classification: Consistent functional categories across phage genomes

📅 Temporal Framework (Chronological Order)

Disease Progression Timeline:

  • t0-over42: >42 months before diagnosis (earliest timepoint)
  • t0-36: 36 months before diagnosis
  • t0-30: 30 months before diagnosis
  • t0-24: 24 months before diagnosis
  • t0-18: 18 months before diagnosis
  • t0-12: 12 months before diagnosis
  • t0-6: 6 months before diagnosis
  • t0: Time of celiac diagnosis (reference timepoint)

📊 Statistical Framework

Mixed-Effects Models: Same rigorous approach as contig analysis

Formula: ~ Dx.Status * onset_timeline_combined + Sex + Age.at.Gluten.Introduction..months. + HLA.Category + feeding_first_year + Delivery.Mode + (1 | patientID)

Random Effects: Patient-specific intercepts to handle repeated measures

Multiple Comparison Control: Appropriate statistical thresholds

📊 Mixed-Effects Negative Binomial for Count Data

Method: glmmTMB with nbinom2 family and log link with offset

Status: ✅ Subset Complete - Demonstrates overdispersion handling

Results: Successful modeling of count-based abundance data with proper variance structure

Figure PHROG-8: PHROG Abundance Model 2 (Negative Binomial) heatmap showing significant effects with proper handling of count data overdispersion.

📊 PHROG Abundance Models Summary

  • Multiple Approaches: Both linear (limma-voom) and count-based (negative binomial) models
  • High Sensitivity: 247 significant abundance changes detected (limma-voom)
  • Quantitative Changes: Captures both presence/absence and abundance shifts
  • Overdispersion Handling: Negative binomial models address variance > mean appropriately
  • Precision Weighting: limma-voom accounts for mean-variance relationship
  • Repeated Measures: Proper correlation structure for longitudinal data
  • Functional Resolution: Gene family-level abundance provides mechanistic insights
